# 人生の季節を数える

生年月日を入れると、**ルネーションナンバー**と、いま自分が人生のどの季節（月相）にいるかが出ます。
出生時刻はいりません。

👉 **https://kira-ring777.github.io/lunation/**

## 出るもの

- 生まれた日の直前の新月
- ルネーションナンバー（0〜29）
- 生まれたときの月相
- いまの月相と、その季節ですること
- 次の季節に移るまであと何年
- 0〜89歳の一覧表

## 数え方について

月が満ちて欠けてをひとめぐりするのに、およそ30日。その1日を1年に置きかえると、およそ30年でひとめぐりする満ち欠けになります。だいたい3〜4年ごとに季節が変わり、30年たつと生まれたときの数字に戻ります。

この数え方は、鏡リュウジさん『ルネーション占星術』の「プログレス・ルネーション」をもとにしています。季節ごとの過ごし方は、この本にくわしく書かれています。

## 計算について

新月の日付は [Swiss Ephemeris](https://www.astro.com/swisseph/) で計算した 1920〜2045年の実データ（1,560件）を使っています。うるう年もそのまま扱えます。

⚠️ 月齢を表示するサイトの数字は、この数え方とは1つずれることがあります。月齢は「新月になった瞬間」からの経過時間で計りますが、この数え方は「新月の**日**」を0として数えるためです。
